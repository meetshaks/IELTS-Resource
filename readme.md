📚 IELTS Resource Hub
A clean, modern, and fully responsive single-page website that organizes high-quality IELTS preparation materials. Designed to help students easily find mock tests, official Cambridge books, computer-based practice platforms, and additional skill-building resources without the clutter.

Website PreviewLicense

✨ Features
Fully Responsive: Looks stunning on both desktop and mobile devices.
Modern UI: Clean, card-based layout with smooth hover effects.
Categorized: Resources are neatly divided into logical sections for easy navigation.
Zero Dependencies: Built with pure HTML and CSS. No frameworks or build tools required.
Fast Loading: Lightweight code ensures the page loads instantly.
📂 Resources Included
This website currently organizes the following external resources:

1. Full Mock Tests & Exam Libraries
IELTS Exam Library - Extensive library of online IELTS tests.
Jumpinto IELTS - Free online authentic practice tests.
2. Official Books & Computer-Based Practice
Cambridge Books 1 to 21 - Official Cambridge IELTS test books.
IELTSMATE - Cambridge question bank in a computer-based test format.
3. Additional Practice Resources
IELTS Practice Online - Comprehensive hub for practice materials, tips, and sample answers across all four skills.
🚀 How to Use
Option 1: View Locally
Clone this repository:
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
Navigate to the project folder.
Double-click the index.html file to open it in your default web browser.
Option 2: Deploy to GitHub Pages (Free Hosting)
Upload the index.html file to your GitHub repository.
Go to your repository Settings.
In the left sidebar, click on Pages.
Under "Build and deployment", select Deploy from a branch.
Select the main (or master) branch and the / (root) folder, then click Save.
Wait a minute, and your site will be live at https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/
🛠️ Customization
Want to add more resources?

Open index.html in any text editor (like VS Code or Notepad).
Copy one of the <div class="card">...</div> blocks.
Paste it into the category section you want.
Update the title, description, and href link.
Save and push to GitHub!
