# 📚 IELTS Resource Hub

A clean, modern, and fully responsive single-page website that organizes high-quality IELTS preparation materials. Designed to help students easily find mock tests, official Cambridge books, computer-based practice platforms, and additional skill-building resources without the clutter.

---

## ✨ Features

- 📱 **Fully Responsive** – Looks great on desktop, tablet, and mobile devices.
- 🎨 **Modern UI** – Clean card-based design with smooth hover effects.
- 📂 **Well Organized** – Resources are divided into logical categories for easy navigation.
- ⚡ **Zero Dependencies** – Built using only HTML and CSS. No frameworks or build tools required.
- 🚀 **Fast Loading** – Lightweight and optimized for quick performance.

---

## 📂 Resources Included

### 📖 Full Mock Tests & Exam Libraries

- **IELTS Exam Library** – Extensive collection of online IELTS practice tests.
- **Jumpinto IELTS** – Free authentic IELTS practice tests.

### 📚 Official Books & Computer-Based Practice

- **Cambridge IELTS Books (1–21)** – Official Cambridge IELTS test books.
- **IELTSMATE** – Cambridge question bank in a computer-based test format.

### 📝 Additional Practice Resources

- **IELTS Practice Online** – Comprehensive collection of practice materials, sample answers, strategies, and tips for all four IELTS skills.

## 🚀 Getting Started

### Option 1 — Run Locally

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
```

2. Navigate to the project folder.

3. Open `index.html` in your preferred web browser.

---

### Option 2 — Deploy with GitHub Pages

1. Upload the project files to your GitHub repository.
2. Open your repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (or **master**)
   - Folder: **/** (root)
5. Click **Save**.
6. Wait a few moments and your website will be available at:

```
https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/
```

---

## 🛠️ Customization

To add more resources:

1. Open `index.html` in your preferred code editor.
2. Copy an existing resource card:

```html
<div class="card">
    ...
</div>
```

3. Paste it into the appropriate category.
4. Update:
   - Title
   - Description
   - `href` link
5. Save your changes and push them to GitHub.
